# Historical experiment code and reusable primitives

The active experiment is described in [Geometry Map Experiment](<../../Geometry Map Experiment.md>) and implemented under [scripts/geometry_map](../geometry_map/README.md).

The `public_panel_*` family implements the deferred DINO-WM Reach/Frankenstein campaign. Its [original code map](../../docs/archive/deferred-threads-2026-09-05/snapshot/scripts/cgs_pilot/README.md) and [scientific plan](../../docs/archive/deferred-threads-2026-09-05/snapshot/WORLD_MODEL_SONAR_PLAN.md) are preserved for reference. Other scripts largely belong to older driving, RoboCasa, V-JEPA transfer, and VLA branches.

Source files and tests remain in place for reproducibility and reuse. Existing shell pipelines do not define the current execution sequence. Admit an old primitive only when the current geometry and causal evidence justify it.
