# Morning Ideation

Historical ideation note. The later [Geometry Map Experiment](<Geometry Map Experiment.md>) governs current execution: geometry and causal-use validation precede operator selection, so the early static-Sonar/HMM arm proposal below is not the current pilot. The [September 5 requirements audit](<Geometry Map Audit 2026-09-05.md>) records outstanding implementation gaps and corrections; historical compute-status statements below are not live status.

The three VLA/MATS machines are now stopped, saving about $0.72 per compute-hour; their important outputs are preserved locally, while the stopped disks remain recoverable. I kept the JEPA/world-model machines available. Previously, we ran interventions during full episodes because a causal steering method changes the selected action, which changes the next observation, which then changes every later planner state. You cannot measure that closed-loop behavioral effect by editing a prerecorded video. The mistake was using expensive closed-loop episodes for fitting, debugging, and parameter selection too. We should preprocess a fixed trajectory bank once—frames, simulator states, snapshots, actions, goal embeddings, activations, candidate plans—and do almost all localization, fitting, ablations, and dose selection through offline replay and short snapshot forks. Only the final surviving intervention needs complete closed-loop episodes.

Assuming “ReachWise” means MetaWorld Reach-Wall, it is a good first task: MetaWorld is a standard 50-task simulated manipulation benchmark, and Reach-Wall contains meaningful approach and obstacle-navigation phases rather than trivial straight-line reaching. [MetaWorld](https://metaworld.farama.org/) and Push-T are both directly supported by the released [JEPA-WM code and paper configurations](https://github.com/facebookresearch/jepa-wms). I recommend beginning with 12 fixed Reach-Wall initial-state/goal pairs and three arms: unsteered JEPA-WM, static Sonar, and the same Sonar operator with soft HMM routing. That is 36 complete pilot episodes, with all three arms replaying exactly the same 12 starts. The primary baseline is the frozen JEPA-WM checkpoint with its normal planner and no activation edit—not COAST and not a published percentage from another harness. Static Sonar is an ablation that tells us whether temporal routing contributes anything. Before those 36 episodes, snapshot forks should test whether each intervention changes planner rankings, actions, and immediate simulator progress in the intended direction. If it cannot do that, we stop without paying for a large rollout study.

Twelve pairs are a screening experiment, not evidence of statistical significance. If the pilot shows a substantial and consistent paired improvement, we freeze the winning operator and evaluate it against unsteered JEPA-WM on 48 new paired starts, meaning 96 confirmation episodes; we expand to 96 pairs only if the confidence interval is still informative but inconclusive. Around a 50% success rate, 96 independent unpaired episodes have a rough 95% margin of error of ten percentage points, although paired starts can improve precision because each intervention is compared against the exact same problem instance. This means 48–96 pairs can support a large improvement, perhaps 15–20 percentage points, but it cannot convincingly establish a tiny 3–5 point gain. We should report the paired success difference, its confidence interval, a paired randomization or McNemar test, and continuous measures such as final goal distance and progress—not pretend every frame is an independent sample. The original [DINO-WM paper](https://arxiv.org/abs/2411.04983) actually used only 50 initial/goal states for each of Maze, Wall, Reach, and Push-T, plus 10 instances for the slower deformable-object tasks; its main table did not provide confidence intervals or formal significance tests. The newer [JEPA-WM study](https://arxiv.org/abs/2512.24497) used 96 independent episodes per evaluation and reported variation across runs, which is better but still mainly capable of distinguishing fairly large effects. Limited statistical power is therefore a real weakness in robotics papers, not something we should imitate or conceal.

I would not pivot to purely descriptive mechanistic interpretability, because that risks producing another feature catalogue like the V-JEPA transcoder paper without demonstrating that the features matter. The stronger and cheaper research direction is causal mechanistic mapping: use cached trajectories to discover where JEPA-WM represents task progress, obstacles, contact, and predicted action consequences; test candidate subspaces with activation patching and snapshot forks; then run full episodes only for a causal operator that survives. We should let JEPA reveal its model-native coordinates instead of assuming that simulator axes or success/failure labels are its natural representation. Simulator variables are evaluation anchors: we ask which latent geometry best predicts them and which intervention actually changes planner decisions. HMM routing remains conditional—it enters only if older history predicts next-step latent innovations beyond the current state, soft routing beats static routing, and the resulting edits are materially different. The resulting paper would make a tighter claim: a task-relevant latent geometry was identified, causally linked to planning, and used to improve behavior on paired Reach-Wall trials, with Push-T as replication. That is more novel than descriptive transcoder features and much cheaper than launching the entire Frankenstein recipe across hundreds of episodes.
