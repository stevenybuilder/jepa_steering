## Sample size and costs must be frozen before launch

The original useful effect is 5 percentage points. The 96-scenario reserve can
support a valid independent re-test, but is not thereby adequately powered for a
five-point improvement. Existing counts show substantial win/loss cancellation.
The supplemental paired normal-approximation sensitivity uses

`n = (z_(1-alpha/(2m))*sqrt(q) + z_power*sqrt(q-delta^2))^2 / delta^2`,

where q is win-plus-loss probability, delta the target success-rate improvement,
m=8 comparisons, alpha=.05 and per-comparison power=.80. This matches the
published MedCalc unadjusted example (q=.30, delta=.10 gives 234 pairs).

| Assumed discordant fraction q | Approximate n for 5-point gain | Approximate n for 10-point gain |
|---|---:|---:|
| .20 | 1,020 | 253 |
| .30 | 1,532 | 381 |
| .40 | 2,044 | 509 |
| .50 | 2,555 | 637 |

These are independent paired scenarios per task, not GPUs, candidate actions,
training seeds or bootstrap draws. They are **planning sensitivities**, not a
final sample size, joint 80% power to beat both controls, or a guarantee of an
improvement. A launch contract must address joint comparison power, nuisance
uncertainty, generation/access rules, runtime and total dollar cap. Do not
retroactively replace the useful-effect target or stop when significance appears.

broad hourly authorizations were superseded by preserve/pause. All active compute
