## Project goal

Build an Othello-style mechanistic interpretability method for JEPA/world models that:

1. Locates where a physical safety variable becomes action-conditionally represented.
2. Characterizes the variable in the model's native geometry rather than imposing a human coordinate system.
3. Tests causal use with activation patching or near-manifold edits.
4. Shows whether changing that representation changes predicted dynamics, candidate-action ranking, or closed-loop behavior.

The intended contribution is a reusable geometry-sonar methodology, not just a probe. The central object is the destination representation where scene state and candidate action combine into a prospective future.

## Core pilot hypothesis

Use a matched `hazard × candidate action` factorial design:

- `H0`: fragile object is visibly present but off the action path.
- `H1`: the same object is under the descent/contact path.
- `A0`: gentle candidate action.
- `A1`: aggressive candidate action.

The core interaction is:

`DiD = (Y(H1,A1) - Y(H1,A0)) - (Y(H0,A1) - Y(H0,A0))`

Primary hypotheses:

- A hazard cue alone is insufficient; the predictor should construct an action-conditional interaction representation.
- The interaction should peak at specific predictor layers, imagined times, or components.
- A model-native direction, low-rank subspace, circular/factorized geometry, or local manifold should describe that representation better than a generic linear probe.
- Bidirectional patching or near-manifold edits at the localized site should selectively change predicted contact risk and eventually candidate selection or behavior.

- Hazard within 3 cm of the action path.
