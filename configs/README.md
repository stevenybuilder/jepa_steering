# Configs

Frozen protocols and asset manifests. Each analysis script checks the SHA256 of the
protocol it depends on, so these files are evidence, not settings to tune.

| File | Role |
|---|---|
| `study.json` | Top-level study contract: tasks, arms, populations, precision, and the frozen statistical plan |
| `fixed_response_rank4.json` | The learned rank-four predictor correction: site, fitting data, dose, and controls |
| `hmm_fixed_response.json` | Routing variant of the fixed-response edit used in the development stage |
| `author_correction.json` | Reconciliation of our evaluation rows against the released JEPA-WM checkpoints and tables |
| `decision_geometry_reanalysis_20260913.json` | Registered reanalysis of candidate-cost geometry on the archived common-action diagnostic |
| `mechanism_followup_20260913.json` | Registered follow-up plan for the layer and candidate-decomposition analyses |
| `droid_assets.json`, `navigation_assets.json` | Pinned dataset and checkpoint identities for DROID and the navigation tasks |
